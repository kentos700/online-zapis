# ClinicFlow

Учебный full-stack проект на тему: **«Автоматизированная система расписания для клиник»**.

Приложение автоматизирует:
- регистрацию пользователей;
- управление расписанием врачей;
- онлайн-запись пациентов;
- отмену и перенос записей;
- базовую оптимизацию загрузки врачей;
- просмотр статистики клиники администратором.

## Технологии

- Flask

## Основные возможности

### 1. Регистрация и вход

Система поддерживает три роли:
- пациент;
- врач;
- администратор.

После входа пользователь попадает на соответствующую страницу:
- пациент: страница записи на прием;
- врач: страница управления расписанием;
- администратор: административная панель.

### 2. Управление расписанием врачей

Врач или администратор может:
- добавить рабочий день;
- указать время начала и окончания работы;
- задать длительность слота;
- управлять доступностью графика.

### 3. Запись пациента на прием

Пациент или администратор может:
- выбрать врача;
- выбрать дату;
- выбрать свободный временной слот;
- подтвердить запись.

Перед сохранением запись проходит проверку:
- слот должен существовать в расписании;
- слот не должен быть занят другим пациентом;
- у пациента не должно быть пересечения с другой активной записью.

### 4. Отмена и перенос

- пациент может отменить свою запись;
- администратор может отменить или перенести любую запись;
- после отмены слот снова становится доступным.

### 5. Оптимизация расписания

Система рассчитывает рекомендуемый слот для записи:
- не допускает двойного бронирования;
- предлагает ближайшее доступное время, если выбранный слот занят;
- учитывает длительность слота;
- старается уменьшить разрывы между соседними приемами.

### 6. Административная панель

Администратор получает доступ к:
- списку всех записей;
- управлению врачами;
- управлению пациентами;
- показателям загрузки клиники;
- активации и деактивации пользователей.

## Логика работы приложения

### Инициализация

Файл `app.py`:
- создает Flask-приложение;
- подключает конфигурацию;
- инициализирует базу данных;
- регистрирует маршруты.

Файл `models.py`:
- описывает модели SQLAlchemy;
- создает таблицы при первом запуске;
- добавляет тестовые данные.

Файл `routes.py`:
- содержит бизнес-логику;
- обрабатывает формы;
- управляет регистрацией, авторизацией, расписанием и записями.

## Пример алгоритма оптимизации записи

1. Из расписания врача на выбранную дату генерируются все допустимые слоты.
2. Из базы выбираются все активные записи врача на эту дату.
3. Каждый слот проверяется на пересечение с существующими приемами.
4. Для свободных слотов считается `efficiency_score`.
5. Чем меньше промежутки до и после приема, тем более выгодным считается слот.
6. Слот с лучшей оценкой показывается как рекомендуемый.
7. Если выбранный пользователем слот уже занят, система ищет ближайшее следующее доступное время.

## Тестовые данные

При первом запуске автоматически создаются:
- 1 администратор;
- 3 врача;
- 3 пациента;
- несколько расписаний на ближайшие рабочие дни;
- несколько примеров записей.

Демо-аккаунты:

```text
Администратор:
admin@clinic.local / admin123

Врач:
doctor1@clinic.local / doctor123

Пациент:
patient1@clinic.local / patient123
```

## Как запустить проект локально

### 1. Открыть папку проекта

Откройте проект в VS Code:

```text
d:\project\клиникa\online-zapis
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить приложение

```bash
python app.py
```

```text
http://127.0.0.1:5000
```
